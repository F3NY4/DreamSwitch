# DreamSwitch v2 — полноценная Android-сборка, проверка и ограничения

Это исходный **сборочный набор**, а не APK. Он НЕ содержит игры, ключей Nintendo, прошивки и готового нативного ядра.

## Что реально готово

- Исходный патч клавиатуры (защита от ложного события закрытия IME, сессии).
- Material You используется из исходного Citron Neo; три стеклянные карточки и лёгкая волна — в новом патче.
- Отдельный `applicationId`: `org.dreamswitch.emulator` — установка рядом с Citron Neo без перезаписи его данных.
- Вычисление SHA-256, ZIP-integrity и проверка наличия ARM64 .so в итоговом APK.
- GitHub Actions workflow с полной командой сборки C++ ядра + Kotlin/Android пакета и загрузкой APK как artifact.
- ADB-сценарий запуска и сбора журнала на телефоне.

## Сборка GitHub Actions — без локального Android SDK

1. Создайте **свой новый репозиторий** на GitHub и загрузите туда *содержимое* этого архива (включая `.github/workflows/dreamswitch-android.yml`). Не добавляйте туда NSP, сохранения или ключи.
2. Откройте вкладку **Actions** → **DreamSwitch Android - Build APK** → **Run workflow** → выберите `main` и запустите.
3. После *успешного* выполнения задачи скачайте артефакт `DreamSwitch-Android-arm64-debug-signed`, распакуйте его, установите полученный `.apk`.
4. Если сборка упала, скачайте логи и зафиксируйте сообщение об ошибке. Не считайте любую упавшую компиляцию готовой работой.

CI ещё НЕ запускался: его работоспособность на GitHub runner и итоговая компиляция требуют реальной проверки. Приведённый путь может потребовать больше места/времени, чем есть на бесплатном runner.

## Локальная сборка Linux / Termux не рекомендуется

Для Ubuntu/Debian со скачанными Android SDK 37, NDK 26.1.10909125, CMake 3.22.1, JDK 21 и git запустите:

```sh
bash scripts/build_android.sh
```

Вызов выполнит клонирование полной истории `citron-neo/emulator`, применение патча и `./gradlew assembleMainlineRelease`.
Windows сборка ядра НЕ входит в этот патч. Её следует вести отдельно на MSYS2 CLANG64 по `docs/BUILDING-CITRON-WINDOWS.md` исходного Citron Neo.

## Проверка на телефоне

1. Установите APK на ваш TECNO с Android 14. Для test-base используйте ARM64-сборку. Устройство должно поддерживать Vulkan 1.1+.
2. Включите отладку по USB, подключите к ПК с `adb` и выполните `bash scripts/adb_smoke_test.sh` из папки набора.
3. Приложение должно запуститься. Затем импортируйте **собственные** ключи и прошивку, а также законно полученную игру v1.0.4, для которой у вас есть право пользования.
4. Установите русский мод отдельно. Не смешивайте анализ вылетов с исходной игрой и с модом: прогоняйте каждый случай отдельно.
5. Сохраните логи и сравните чёрные экраны, создание Mii, ввод, переходы по помещениям, сохранения. ВЫСОКОЕ качество графики и плавность нужно измерять на устройстве.

Важно: перенос данных между DreamSwitch и обычным Citron Neo не автоматический (разные Android applicationId). В самом эмуляторе есть функции экспорта и импорта пользовательских данных/сохранений. Перед любым импортом создавайте резервную копию; операции могут перезаписывать старые сохранения.

Не включённые ещё функции: облачный профиль и синхронизация, подтверждённые игровые оптимизации/исправления чёрного экрана, переключатель качества под Tomodachi Life, Windows-дистрибутив.

## Почему этот ответ не содержит готового APK

Текущий контейнер не имеет выхода к GitHub/Gradle и не хранит полный Git-снимок предыдущей сессии. Найти NSP/русификатор на подключенном Google Drive не удалось. Физического доступа к телефону пользователя нет; без ADB невозможно правдоподобно отчитаться о реальном тестировании игры. В этом пакете CI является механизмом получения APK, но сам APK НЕ собран.
