# DreamSwitch

Экспериментальная Android ARM64-сборка эмулятора Nintendo Switch на основе открытого исходного кода [Citron Neo](https://github.com/citron-neo/emulator).

## Сборка APK — без локальной установки SDK

1. Откройте вкладку **[Actions](https://github.com/F3NY4/DreamSwitch/actions)**.
2. Выберите **DreamSwitch Android - Build APK**.
3. Нажмите **Run workflow**, оставив основную ветку `main` и предложенную версию исходников без изменений.
4. Откройте результат запуска и, **только если сборка успешна**, загрузите артефакт `DreamSwitch-Android-arm64-signed` из раздела **Artifacts**. В архиве будет APK.

Исходное ядро и все подмодули загружаются непосредственно на GitHub Actions; пакеты Android SDK, NDK, CMake и JDK устанавливаются автоматически. Рабочий процесс сначала проверяет и накладывает патч, затем компилирует Android-приложение вместе с его нативными библиотеками. При ошибке появится красный статус и диагностический архив, но APK может не быть создан.

## Какие изменения включены

- Отдельный Android package ID `org.dreamswitch.emulator` и название DreamSwitch.
- Ограничение преждевременного закрытия экранной клавиатуры.
- Прозрачные карточки с лёгким оформлением без шейдерного размытия.
- Волнистый индикатор в диалогах импорта/экспорта.
- Поддержка существующей темы Material You из Citron Neo.
- Автоматические тесты патча и проверка ARM64-библиотек в APK.

**Это предварительный билд, а не полностью исправленный эмулятор для Tomodachi Life.** Не подтверждены: успешная полная компиляция, запуск на реальном телефоне, работа игры v1.0.4, русификатор, отсутствие вылетов и повышенная производительность. Полноценный аккаунт/облачная синхронизация, система специальных профилей игры и Windows-приложение пока не реализованы.

**Не загружайте в публичный репозиторий игровые ключи, коммерческие NSP, сохранения с личными данными или игровые файлы.** Они не нужны для компиляции эмулятора.

## Исходные файлы

- `apply_dreamswitch.py` — локальный патчер upstream-кода.
- `overlay/` — дополнительные интерфейсные ресурсы.
- `tests/` — тесты патча.
- `scripts/` — локальная сборка, проверка APK и диагностический ADB-smoke-test.
- `.github/workflows/dreamswitch-android.yml` — ручная GitHub Actions сборка.

Проект основан на открытом ПО с соответствующими исходными лицензиями; внесённые изменения распространяются в рамках применимых лицензий upstream.
