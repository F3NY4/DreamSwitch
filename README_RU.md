# DreamSwitch — восстановительный патч (06.11.2026)

Это **не эмулятор и не APK**. Архив содержит небольшой проверяемый набор изменений для **открытого проекта** [`citron-neo/emulator`](https://github.com/citron-neo/emulator). Предыдущий 4300-файловый снимок из ChatGPT Work недоступен, поэтому патч воспроизводит только перечисленные изменения — не прежние профили и не готовые исправления рендеринга.

## Что включает

1. Защита от преждевременного закрытия виртуальной клавиатуры в Android: ожидание появления IME до 8 секунд, подтверждение закрытия двумя измерениями, идентификатор сессии для отмены устаревших обработчиков. Это **предварительный фикс**, не протестированный на устройстве и не гарантирующий исправление всех проблем с вводом.
2. Стиль Dream Glass на двух карточках экрана импорта и экспорта, без размытия изображения или GPU-шейдеров.
3. Волнистый прогресс-индикатор в диалогах импорта/экспорта: перерисовывается только в диалоге, приблизительно 20 fps при неопределённом прогрессе; во время рендеринга игры не работает.
4. Material You **уже существует** в Citron Neo для Android 12+; здесь сохраняется штатная реализация (поддерживается Android 14).
5. Уже существующие функции: отдельный импорт/экспорт сохранений и полный экспорт/импорт пользовательских данных. Важно: полный импорт **может удалить старые данные**. Перед ним создать резервную копию, проверить целостность ZIP.

## Применение к исходникам

Нужны: исходники `https://github.com/citron-neo/emulator`, Python 3.9+, полный Android SDK/NDK, JDK и доступ в интернет для Gradle и библиотек.

```bash
git clone https://github.com/citron-neo/emulator.git
python3 apply_dreamswitch.py ./emulator
cd emulator/src/android
./gradlew assembleMainlineRelease
```

На Windows используйте `py -3 apply_dreamswitch.py .\emulator`, затем из `emulator\src\android` запустите `gradlew.bat assembleMainlineRelease`. Если проект изменился, скрипт выдаст ошибку; не применяйте изменения вслепую.

Windows-версию компилируйте по официальному [`docs/BUILDING-CITRON-WINDOWS.md`](https://github.com/citron-neo/emulator/blob/main/docs/BUILDING-CITRON-WINDOWS.md). Эта версия патча **меняет только Android UI**, Windows-оптимизации в неё пока не входят.

## Целевые требования для следующих этапов (пока НЕ реализованы)

- DreamSwitch как отдельное приложение с собственным идентификатором пакета, иконками и возможностью установки рядом с Citron Neo;
- профили Tomodachi Life v1.0.4: ПК 1x, Android 0.75x, экономичный 0.5x, с приоритетом пользовательских настроек;
- диагностика чёрного экрана и вылетов на TECNO Camon 20 Premier 5G (Mali GPU) и Samsung Galaxy Tab A9 (Adreno 619);
- дополнительный локальный профиль DreamSwitch и защищённый перенос сохранений между устройствами, в перспективе облачная синхронизация после проектирования аккаунтов;
- реальное тестирование игры и русификатора v1.0.4 на устройствах, протокол FPS, сохранения и вылеты.

## Почему APK отсутствует

В этом окружении нет исходного снимка прошлой сборки и нет сетевого доступа из компилятора к GitHub/Gradle-зависимостям; нативное ядро Citron Neo не собрано. Игра и русификатор из Google Drive недоступны текущему подключению. Этот архив позволяет сохранить промежуточные улучшения без ложных заявлений о совместимости.
